# Соединение фасада — Revit 2024

Готовая DLL: `dist\FacadeJoin2024.dll`. .NET Framework 4.8, x64.

## Загрузка через Add-In Manager

1. Откройте **копию проекта** в Revit 2024.
2. Выделите несколько соприкасающихся элементов фасада категории «Обобщённые модели». Можно выделять целые модельные группы — команда рекурсивно найдёт обобщённые модели внутри выбранных групп.
3. Надстройки → Add-In Manager → **Add-In Manager (Manual)** → Load.
4. Откройте `dist\FacadeJoin2024.dll` из этой папки.
5. Выберите `FacadeJoin2024.JoinCommand` → Run.
6. Проверьте стыки в 3D и на разрезе, состав/число экземпляров групп и отчёт. Ctrl+Z отменяет результат команды целиком.

Если выделения нет, команда предложит выбрать элементы/группы и нажать «Готово». Если выделен только один элемент, выделите несколько и повторите запуск. Команда работает только между выбранными моделями, а не со всем фасадом автоматически. Элементы связанных RVT не обрабатываются.

## Обычная установка

Закройте Revit и выполните PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File "D:\Vasilii\Job\a101\projects\FacadeJoin2024\Install.ps1"
```

После перезапуска: Надстройки → Внешние инструменты → **Соединить фасад**. Скрипт добавляет только манифест текущего пользователя; DLL остаётся в `dist`, папку нельзя переносить после установки. Для удаления удалите `%APPDATA%\Autodesk\Revit\Addins\2024\A101.FacadeJoin2024.addin` при закрытом Revit.

## Поведение и ограничения

- Используется штатный `JoinGeometryUtils.JoinGeometry`: удаляет границу совместимой соприкасающейся геометрии. Не перемещает элементы, не закрывает зазоры и не превращает экземпляры в одно семейство.
- Группы никогда не разгруппировываются, не пересоздаются и не делаются уникальными. Соединение пробуется непосредственно для их элементов. Если Revit запрещает конкретное соединение из-за группы, геометрии, доступа в рабочем наборе или другой причины, пара откатывается и записывается в отчёт. Обход ограничений через разгруппировку не предусмотрен.
- Revit сам управляет изменениями повторяющихся экземпляров групп; проверяйте также другие экземпляры того же типа группы. Плагин не гарантирует, что Revit разрешит все соединения внутри группы или между группами.
- Поиск соседей по габаритам с допуском 0,1 мм. Это только фильтр кандидатов: фактическое соединение решает Revit. Уже соединённые пары пропускаются; порядок существующих соединений не меняется. Для новых пар порядок определяется координатой X, затем ID.
- Отдельная транзакция на пару; предупреждения и ошибки Revit приводят к откату пары. Успешные изменения собраны в одну операцию Undo. Свыше 20 000 соседних пар команда завершится до изменений: выделите меньший участок. На больших выборках обработка может занять время.
- Отчёты: `%LOCALAPPDATA%\A101\FacadeJoin2024\Reports`. Содержат ID обоих элементов, ID групп и причины отказа Revit. ID группы -1 означает отсутствие группы.

## Сборка

```powershell
dotnet build .\FacadeJoin2024.csproj -c Release
# Другой каталог установленного Revit 2024:
dotnet build .\FacadeJoin2024.csproj -c Release '-p:RevitPath=C:\Program Files\Autodesk\Revit 2024'
```

Требуются SDK .NET и reference assemblies .NET Framework 4.8. DLL Revit API не включаются в поставку.

Проверено: сборка с установленными RevitAPI/RevitAPIUI 2024, без ошибок и предупреждений. Запуск команды и визуальный результат на пользовательской модели не проверены.
